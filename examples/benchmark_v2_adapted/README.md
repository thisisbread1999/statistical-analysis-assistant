# Evaluation declarations

This directory separates our policy from the unchanged teammate snapshot in `../benchmark_v2/` at commit `b7eff1c4a8035f196ac4bfc73ef3fe88956dadb5`.

The 31 adapter JSON declarations and source SHA-256 map are generated by `python benchmark_suite.py --export-only` without creating or calling a model. They contain explicit TEST FIXTURE continuation recipes and primary pause/stop expectations; they are not human labels or measured scores. Existing source hashes are checked before loading or re-exporting, so modified source data cannot silently redefine expectations. Every actual run freezes its selected declarations in `preregistered_cases.json` before creating live agents. See `docs/BENCHMARK_V2.md` for policy adaptations and the evidence format.
